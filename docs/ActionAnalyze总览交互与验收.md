### Qt Stored 总览回执

「监控 → 行为分析 → 总览」的单段预览由 `OfflineSegmentOverview` 承载。页面类型为时间线和结果表。外层沿用工作台内容框，工具带、`ResultTableHost` 的 Compact 操作条和 `StructuredFieldView` 提供共享外观与详情。对照页面为监控 Dock 的进程定向监控与 WinAPI 监控。瀑布沿接收 QPC 绘制，支持键盘和鼠标时间范围。关键字、类别和已提交时间范围共同作用于瀑布和事件表。过滤隐藏当前行时继续显示其详情。项目页选择仅用于对照身份。预览上限为 64 MiB 和 4096 条记录。API／ETW 分类、强对象身份、证据图和实时状态仍待接入。

`80877163b` 对应的源码通过 HostX64 Release 构建。`Ksword5.1/x64/Release/Ksword5.1.exe` 的 SHA-256 为 `10EE528AA409328FB7E7F907C7FAAA58A2E2311E15BE26B1203941A72B26B772`，日志为 `.codex-build-logs/ksword-build-check-20261124-232011.raw.log`。双语和主题门禁通过。独立 QtCore 读取夹具通过 13 项断言，其中事件 `0` 与归档记录 `29` 独立校验，坏尾保留已验证前缀。夹具文件和 EXE 已清理。实际导航、焦点、窄窗、深浅主题和 DPI 尚待交互桌面验收。

后续正式 Qt 复验覆盖「项目与采样」直达总览、独立 ETW 筛选和原位重读。总览也可启动同一进程实例的 CPU／I/O 区间分析，并独立报告 ETW 覆盖。真实窗口及 QtCore 读取器结果见[目录身份绑定复验](../tools/action_analyze_validation/qt/ETW-Readback.md#目录身份绑定复验)。

## 完整总览入口与布局（计划）

目标路径为「监控 → 行为分析 → 总览」。打开后显示当前项目和采样。用户缩小时间、类别或来源范围，查看事件及关联证据，再通过右侧动作对明确对象提交控制。规则和断点分别作为「行为分析」内部的页签，切换时保留各自草稿和总览筛选。共享调试动作及状态在各页签沿用同一会话、对象范围和回执，规则与断点编辑时收起左瀑布，保留底部证据图与调试区。

| 区域 | 布局和职责 |
| --- | --- |
| 左侧瀑布 | 窄栏，时间沿 Y 轴从上往下推进，类别泳道沿 X 轴排列。支持增减及调整泳道顺序，显示范围、刻度和密度。拥挤时用有标签的聚合桶，保留活跃范围可见。 |
| 中央事件表 | 表格占主要空间。上方为可多选的类别图标和分别开关的 API／ETW 显示过滤。默认列依次为时间、PID、TID、进程、事件。结果表用 `Compact` 操作条承载复制和导出，导出标明实际范围。表头上方控件与表共享左右边界。 |
| 右侧动作 | 本地计划 `docs/ActionAnalyze工具栏逐项功能核对.md` 中的 T01–T11 和 T14 共 12 项。本会话、选中对象、活动线程／帧分别成组。旧图的回滚和热重载留在延期清单。一键调查保留独立入口，相机仍是选中内存 dump。 |

## 时间范围、焦点和动作对象

- 在瀑布中拖出时间范围，可跨多个类别泳道。在拖动期间预览边界，松手提交半开区间 `[起始, 结束)` 与命中的类别。向上拖动得到相同区间。`Esc` 取消草稿，保留上次应用值。时间游标停在原位置并暂停当前视图跟随。通过「恢复实时」重新跟随。瀑布、类别和 API／ETW 控件只改显示范围，采集、归档和调试控制继续由各自所有者运行。
- `Tab`／`Shift+Tab` 依次进入筛选、瀑布、表、动作和证据图。瀑布内上下键移动时间游标，左右键切换泳道，`Shift` 加方向键扩选，`Enter` 应用。过滤按钮用 `Space` 切换。事件表保留原生键盘选择、多选和明确的详情入口。图内可用键盘选择节点和关系，并通过可读的关系列表访问同一证据。全局动作绑定按运行时控制规范登记，控件提示从实际动作登记源取当前绑定。[运行时控制规范](运行时控制开发规范.md)
- 时间框选、实时追加、源切换、排序和图的迟到更新都不抢焦点或隐式改选。表格选择以 `eventId` 为锚。图选择以当前 `sampleId` 与进程／线程实例为锚。选中对象因过滤离开视野时显示其状态；控件不得自动换到邻行或旧样本中的同 PID。显示、查看证据、选择控制对象由用户分别操作。
- 图上明确选择对象并确认「仅节点」或「含后继」范围后，右侧动作按请求时的实际对象和停点冻结范围。步进针对所选有效停点的线程或帧。在途请求的目标随回执展示，后续改选仅影响下一次请求。各端从本端共享动作定义取得名称、图标和键位，从本端控制状态取得动作范围、禁用理由及恢复入口。禁用理由也可经键盘到达的状态或动作菜单查看。

| 工作包 | 入口与行为 | 验收 |
| --- | --- | --- |
| 显示筛选 | 事件表上方提供关键字、类别、独立 API／ETW 开关、选中进程／线程范围和时间范围。更多条件放在紧凑扩展区。组内多选取并集，组间取交集。明确显示生效条件、结果数、清除入口和来源未知状态。筛选联动瀑布与事件表。 | 核对鼠标与键盘、窄窗换行、多条件组合、未知来源、空结果、清除，以及隐藏选中事件后按同一 ID 恢复。筛选仅修改显示投影。 |
| 对象右键菜单与 Dump | 底部图节点和可键盘访问的对象列表共用进程／线程菜单。支持查看证据、用此对象筛选、复制标识和「导出 Dump」。历史节点导出已有且身份匹配的证据。实时节点在有效权限与强实例核验通过时按明确请求生成诊断 Dump。线程范围使用已有线程证据，界面显示所属进程及实际导出的范围。 | 显示导出类型、结果位置、部分数据与失败原因。测试鼠标／键盘打开、线程同 ID 复用、所属进程不匹配、历史无证据、只读打开、取消和写失败。源对象采用采样与进程／线程实例 ID。 |

### 网络记录和原始字节的存盘顺序

沿用 `samples/<sampleId>/` 的目录结构。流内段编号从 1 开始，文件名为 20 位零填充编号，段内记录序号单调递增。界面按有效时钟排序，以稳定事件 ID 处理同一时刻的选择和跳转。

| 位置 | 内容 |
| --- | --- |
| `raw/<ordinal>.ksaseg` | 保存源记录、实际通信字节或其内容引用。常规报文集中成块写入。元数据保存源与时钟、采集层、原长度（若已知）、实存长度、截取策略和方向。来源只给出流信息时标记「仅元数据」。 |
| `blobs/sha256/<first2>/<hash>` | 使用采样内的通用 BlobStore 保存超出内联上限的内容和 Dump 数据。清单绑定对象、格式、字节范围、长度和哈希。 |
| `records/<ordinal>.ksaseg` | 保存可筛选的规范事件、出站目的 IP 和原始记录引用。多个事件按实际证据关联到同一流，字节数沿用各来源的测量口径。 |
| `control/<ordinal>.ksaseg`、`checkpoints/<generation>.json` | 控制流记录采集状态和用户明确发起的动作。检查点发布各流已刷盘前缀和依赖范围。出站地址索引从规范事件重建。 |

先保存字典和实际字节，再保存引用它们的事件，最后刷盘并发布检查点。达到采样配额时按冻结配置执行，并记录停止范围和丢失计数。重新打开时展示经过检查点验证的结果和单独标识的可恢复尾部。验收用带已知字节的本地测试通信逐字节比对，并核对坏尾后保留的前缀和引用。

## 状态和证据锚点

- 投影区分别显示未加载、加载中、成功空结果、部分资料、失败和来源不可用。来源显示开关和实际来源覆盖分别呈现。进入、返回及异步完成沿用真实事件阶段，缺核对字段时标明未知。能从当前行打开原始来源、阶段、时间／时钟、进程／线程实例及证据引用。[基础身份及字段契约](../schemas/action_analyze/base-contract-v1.md)
- 状态条区分请求已接纳、实际生效与已回读。停点区分命中线程、组部分停止、组全部停止、原生附带暂停与内部探针屏障。继续发送后等待实际回执，恢复未决时显示责任和重查入口。历史采样可查看和导出证据，实时控制动作按会话资格禁用。完整要求见本地计划 `docs/ActionAnalyze同步全局断点与性能复查.md`。[只读停点快照](../schemas/action_analyze/README.md#停止组只读投影草案)
- 图的候选边与已核实边同时用文字和线型区分。边显示关系、源端、目标端及证据状态，明确打开可回到对应 `sampleId`、事件和来源记录。缺证据保留为候选，多父边保留。筛掉的必要上下文可淡化呈现并注明口径。瀑布、表、图和详情使用一致的采样身份与水位。
