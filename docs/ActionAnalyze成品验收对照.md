验收目标按[总览交互](ActionAnalyze总览交互与验收.md)、[工具栏](ActionAnalyze工具栏逐项功能核对.md)和[33 项工单](ActionAnalyze施工任务与契约落点.md)逐项检查。当前记录为返工中的验收底稿。

## 概念图逐区核对

| 区域 | 当前可用范围 | 待闭合 |
|---|---|---|
| 开始监控 | Qt「监控 → 行为分析 → 总览」输入目标 PID 和 ETW Provider GUID，启动及停止单进程 ETW 预览。当前设置上限 120 秒。 | 受控启动、正式采样计划、选择后端、实时写档和产品窗口实测。 |
| 同一工作台 | 归档和实时共用一个总览、事件表、瀑布、筛选、详情及底部图控件。 | 已结束实时与历史结果随时切换、项目目录直接打开证据流、按需加载及长采样。 |
| 左侧瀑布 | 预览可选记录和时间范围。 | 跨类别泳道范围、可重排泳道、实时追加的游标稳定和密度聚合实测。 |
| 中央表和筛选 | 共享 Compact 结果表支持显示筛选、复制和表格导出。直接 ETW 来源可筛选。独立归档的声明保留未知。 | API 实时来源和独立归档来源绑定、三端真实记录对照。 |
| 右侧动作 | 见下表。 | 控制及调查的共同右栏、统一停点回执与全部实测。 |
| 底部流程图 | 当前事件与其可核对的归档进程／线程引用连线。右键和键盘可查看、筛选或复制标识。独立图控件通过 15 项离屏断言。 | 跨事件因果图、实时强实例对象节点、共享编辑页中的图位置和选中对象内存导出。 |
| 固定状态 | 同一 Qt 工作台各页共用 ETW 生命周期状态。原生失败码和未归档状态可见。 | 后端与停点责任、命令生效回读、可恢复失败和真实窗口交互。 |
| 行为规则 | 独立页可打开、编辑和保存 UTF-8 草稿，可检查并用内置合成事件回放。 | 正式项目规则包、真实采样等价回放和来源覆盖。 |
| 断点 | 独立页可按模块符号或 RVA 编辑、增删和校验内存草稿，状态显示未绑定。 | 持久化、项目保存与加载、模块重绑、真实命中和撤销。 |
| 网络 | 已归档的识别记录可查看端点、捕获状态和保留字节预览。 | 实时采集、采样归档、出站地址查询、三端重开及断连。 |
