# UI 控件逐页整理

本轮逐个读取页面构建入口并登记控件，不依靠全局修改默认表格模式或脚本批量替换。
所有记录均为实现取舍；编译状态与用户运行验收分开报告。

## 共用几何与外观

- 普通按钮、单行筛选、组合框、数值控件在具体工具行内等高；普通行间距为 8px。
- A/B/C 列组选项显式保留 0 间距；FlowLayout 仍然换行，不固定并列内容或多行提示高度。
- 文字按钮保持按内容自然宽度，统一横向留白；明确的图标工具统一方形尺寸及 16px 图标。
- 主题重建后补回已登记的按钮几何，不覆盖危险、成功、勾选等语义配色。
- 搜索框使用中性实底、无白色描边、5px 圆角与统一内部留白，保留各页提示和过滤逻辑。
- 地址、路径、PID、密码、命令等参数输入保留业务语义；标题栏双模式字段保留紧凑高度。
- 普通内容 Tab 使用柔和选中填充和细主题下划线；切换状态不改变边缘或留白。
- 内存工作台的自绘分段 Tab 同步调整实际绘制；详情侧栏与 ADS 的导航机制保持原框架。

## 表格操作栏的页面判断

Full 保留完整复制、导出、冻结、快照和对比。Compact 仅保留复制、导出。
None 不占用顶部操作条，页面已有业务操作和单元格交互保留。
树形属性控件不属于 QTableView 操作条范围，不为了统一而注入表格功能。
