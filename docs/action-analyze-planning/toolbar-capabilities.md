## 活动会话、历史与执行资格

- **活动会话与可见资料**各自保留实际身份。会话发布 `projectId`、`sampleId`、`sessionId`、`epoch`、所选和实际后端、状态修订及观测时间。可见资料另带 `live`／归档、视图代次、来源和水位。查看历史时，实时会话可以继续运行。会话级动作如仍可用，单独标明目标是哪个活动采样及其范围。历史选区、已结束窗口和导入回执仅提供资料查看与适用的证据导出。R3 与普通 R0 分别报告能力，活采样沿用实选后端。
- **证据选择**用同一采样内的 `eventId`、原始记录引用或对象引用，保留来源实例、来源代次、时钟和观测时间。界面分别标明执行者、目标和观测线程。**执行选择**需要显式对象和范围（如「仅节点」或「含后继」），并由本端所有者核验同一活动采样内的强实例。进程核对 PID 与创建身份，线程另核对所属进程及线程创建身份。区域另带映射／内容版本，连接另带观测快照和连接身份，步进另带有效停点、线程及适用的帧。弱引用允许复制和查看，执行资格另行判断。
- **资格快照**按动作返回已接入、可用性、理由、当前范围、依据的会话和修订，以及重查或恢复入口。未接入、后端不支持、历史只读、无有效选择、身份过期、权限不足、动作冲突和恢复未决分别显示。混合多选逐项列出可用及排除项，部分受理须在确认摘要明确显示。命中线程、停止组部分／全部停止、附带暂停、内部屏障和实际待恢复责任分别回读。历史 `stopId` 只用于定位。
- 排序、追加、筛选、时间框选和证据图晚到的更新只影响显示。隐藏选区保留原身份及提示。切换采样或重新选择只影响下一次请求，保留未提交草稿和已发布结果。[总览选择规则](../ActionAnalyze总览交互与验收.md#时间范围焦点和动作对象) · [身份契约](../ActionAnalyze事件身份与协议契约.md) · [停止组快照](../../schemas/action_analyze/README.md#停止组只读投影草案)

## 冻结请求、幂等、失败与清退

1. **读取资格。** 本端所有者提供只读状态，UI 使用值化投影、实际来源和观测时间。耗时请求走原异步入口。
2. **显式提交。** 冻结 `actionId`、`requestId`、项目／采样／会话／代次、实选后端、预期状态修订和实际目标集合。按动作附范围、依据、停止组或停点引用、版本、策略和预算。确认摘要与实际提交共用该范围。所有者受理时重新核验前提，失效则逐项返回原因，重新选择并确认可发新请求。切页、读档、换选和换工具条宿主不改写在途目标。
3. **回读原票据。** 分别显示已受理、实际生效、已回读和终态。按原请求及代次接收回执，晚到结果仍归原动作。结果包含目标、实际范围、阶段、时间、后端／来源、原始错误、证据引用和未决责任。成功空结果、部分结果、失败、取消及结果未知独立呈现。归档是否已验证提交另带实际水位。
4. **重复、取消及重试。** 同一所有者代次内，同 ID 和相同冻结内容复用原票据。同 ID 内容变化显示冲突。ACK 缺失或等待超时先查原请求。取消申请与取消终态分开，保留部分证据和未决责任。明确重试使用已回读的未解决条目，重新核对身份并关联原票据。待原票据状态明确后才允许重新提交。
5. **清退。** T14 进入清退后收拢普通动作准入，保留对原所有者适用的查询及恢复入口。采集结束、自有责任结清、目标处置及归档结果分开记录。当前需明确选择结束调试后的目标处置和步进时依赖范围。慢归档、失败及关窗仍保留未决项。权威回读确认结清后显示清退完成，旧会话的归档不转授控制资格。[请求与回执职责](../ActionAnalyze施工任务与契约落点.md#6-关键接口需要冻结到什么程度) · [方法与幂等计划](../ActionAnalyze事件身份与协议契约.md)

## 浮窗和停靠带共用动作对象

每端工作台按稳定 ID 为已接入动作维护一个逻辑对象，统一名称、图标、可访问提示、键位、资格及请求票据。停靠带、浮窗、适用的菜单及快捷键从同一对象走同一确认和派发路径。Qt 沿用 `m_actionStrip` 的移动机制，实际快捷键经 `ShortcutRegistry` 登记真实作用域，从登记源更新提示。Light 消费独立的本端动作对象。浮出、关闭、停靠、切 Tab 及切主题只变更呈现，状态区仍可查询原回执和恢复入口。[Qt 工具带](../../Ksword5.1/Ksword5.1/ActionAnalyze/OfflineSegmentOverview.Toolbar.cpp) · [运行时控制规范](../运行时控制开发规范.md)

Qt 沿用监控工作台的 `StyleWorkspaceContentFrame`、`StylePrimaryToolbar`、`FlowLayout`／`NormalizeToolbarLayout` 和 `ResultTableHost` Compact 结果条，Light 沿用 `WorkspaceHost` 和原生布局。正式桌面需记录真实工厂与页签、首帧、鼠标及键盘焦点、可键盘抵达的禁用理由、窄窗、100%／150%／200% 与跨屏、深浅主题和双语长文本。动作验收观察同一 ID、同一在途票据、一次提交和宿主切换前后状态。[总览双端验收矩阵](../ActionAnalyze总览交互与验收.md#完整总览双端验收矩阵)

## 交接

用户原话「严禁在我问一个问题过后就停下来，任务完成之前不能停下来，全部继续推进」。本批交付 UI 契约和 Qt 五个现有入口的只读资格模块。主代理接入现有按钮、工程和语言包后，可检查活动与历史并存、浮窗共享、在途改选和部分失败。其余动作沿 [11 项产品验收清单](../ActionAnalyze产品验收清单.md) 登记实际产品证据。
