# PiDDB 单条详情与删除

`r0 piddb-detail --entry ADDRESS [--max-rows N] [--json]` 从有界 PiDDB 快照读取指定内核记录的地址、驱动名、时间戳和加载状态。默认最多读取 4096 条；查询截断时，找不到该地址不代表记录不存在，返回 6 并报告 `complete=false`。查询结果是快照，不是锁定的对象租约。

`r0 piddb-delete --entry ADDRESS --name NAME --timestamp N --load-status N --confirm [--json]` 使用完整身份删除目标；数值支持十进制和 `0x` 十六进制，NTSTATUS 的原始 32 位值可写为十六进制。名称、地址、时间戳、状态必须来自同一条记录。该操作会改变内核驱动加载历史，不能由本命令自动撤销。

命令先调用只读预检，驱动重新校验完整身份；预检未返回预期状态或身份不匹配时绝不提交。确认后使用同一身份调用驱动的强制删除路径，驱动在内核锁下重新核对并检查目标已不存在。输出 `expectedEntry`、`preflight`、`commitAttempted`、`commit` 和 `deletedAndVerified`，保留两次操作的协议状态、原始 NTSTATUS、传输错误和匹配身份。返回 0 要求提交响应完整、身份匹配、操作状态和 NTSTATUS 成功；验证失败或提交后身份不一致返回 6，不能盲目重试。2 表示设备打开失败，3 表示操作失败，4 表示响应格式/身份不一致，5 表示能力不可用。

该命令使用现有驱动协议，不会自动加载驱动或修改符号配置。PiDDB 私有布局、当前内核配置和访问权限可能导致预检拒绝；应以实际状态为准。
