# 实时结构采样与在线内核栈验收

## 验收范围与不可替代项

本轮要求为：EPROCESS、ETHREAD 的实际采样严格覆盖率分别超过一半；实现在线目标线程
内核返回地址展开，并在自有 Win10、Win11 虚拟机通过 CLI 实测。虚拟机不进行 GUI 自动化。
磁盘布局、合成字节解码、R3 用户帧、R0 指针线索和离线转储帧均不能替代这两项现场验收。

当前结论（2026-11-22 10:16 UTC之后）：双VM的EPROCESS/ETHREAD严格过半实时采样、
等待/忙碌目标的原始保存上下文内核链均已取得真实CLI回执并独立核验。完整度仅指原始
内核链抵达有真实机器帧证据的用户态边界，不包含用户调用链，也不外推至未支持的内核。

最新结果见下方“保存上下文后端最终双机实测”；生命周期历史和压缩体积另列。后面的早期构建哈希和原始套件
均作为分阶段历史证据保留，不代表当前 Release 文件仍具有相同哈希。

严格字段覆盖率分母为精确分片的全部符号行，含父结构、未支持类型和 union 分支。
分子 `coverageRows` 仅包含实际有效字节完整且成功解码的非 union 行，并按
`(absoluteOffset, width, bitOffset, bitWidth)` 去重。每个对象和每台 VM 分别要求
`coverageRows * 2 > totalRows`，不将四个结果合并平均。

## 对象体采样实现

- 共享协议：`shared/driver/KswordArkStructureSampleIoctl.h`，函数号 `0x941`。
- 后端：`KswordARKDriver/src/features/process/structure_sample*.c/.h`。
- 统一 R3 入口：`ArkDriverClient/ArkDriverStructureSampling.cpp`。
- 共同解码：`shared/usermode/StructureSampleProjection.cpp`。
- CLI：`process layout sample`、`process thread layout sample`。
- GUI：原 EPROCESS 页和两个线程详情入口复用同一快照投影，不混合不同采样批次。

请求不含地址、偏移或长度；驱动只引用由 PID/TID 和创建时间核验的对象。加载中内核的
完整 PE/RSDS 必须命中编译允许列表，根范围来自该精确 PDB 的 sizeof，而非用户请求、
邻版布局、池费用或指针推断。当前精确配置为宿主 `19041.7844`、Win10 `19041.631`、
Win11 `26100.9711`。持有对象引用不表示对象内容被冻结，所有结果均明确 `atomic=false`。

每字节有效位决定是否可解码；未完整读取不能显示假零。指针仅作数字展示，不读取其目标。
union 原始解释有独立标签，且全部排除于严格覆盖分子。聚合节点保持结构导航，不充当成功字段。

## 剩余现场用例

两 VM 使用 `LiveKernelDiagnosticVmTarget.exe` 的自有等待和忙循环线程。部署前核对原驱动
和 CLI 哈希、签名准入及服务占用，不能改宿主驱动或客体安全策略来制造通过结果。

保存每次原始 JSON 后，用夹具独立记录的 PID、TID 和创建时间运行验收器，例如：

```powershell
python tools/verify_live_structure_sample.py --receipt <process-receipt.json> --profile <exact-process.tsv> --pid <fixture-pid> --process-creation <fixture-process-filetime>
python tools/verify_live_structure_sample.py --receipt <thread-receipt.json> --profile <exact-thread.tsv> --pid <fixture-pid> --process-creation <fixture-process-filetime> --tid <fixture-tid> --thread-creation <fixture-thread-filetime>
```

验收器的 `evidenceConsistencyVerified=true` 只表示所给文件内部自洽、过半且有公开字段对照；
`acquisitionIndependentlyProven=false` 明确提醒仍须保留部署哈希、真实来宾命令执行与退出码，
不能单凭一份可伪造的 JSON 宣称 VM 现场通过。
