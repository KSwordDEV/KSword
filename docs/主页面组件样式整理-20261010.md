# 主页面组件样式整理

## 取舍

沿用当前主题与密度，通过工具区底面、明确的功能边界、适量组间留白和中性表头降低视觉负担。各页面在构建入口明确登记需要调整的控件，不递归扫描所有控件进行替换；属性、详情及独立配置窗口不属于本轮范围。

## 逐页范围

| 页面 | 本轮调整 |
| --- | --- |
| 进程列表、线程、CrossView | 保持单行控制区与图表高度，增加轻工具带，筛选下拉完整绑定各状态底面 |
| 创建进程 | 方式、基础参数、安全属性、启动参数、输出及令牌分组保持完整轻边界，区间16、区内紧凑 |
| 内存目标、进程/模块 | 目标工具区、两张表的独立操作区和扫描阶段边界更明确 |
| 内存调试、Hyper-V、PFN、系统内存 | 保留参数与结果同屏，按实际采集、筛选、定位流程整理工具区 |
| 内存证据 | 原有扫描参数组统一中性表面及边界 |
| 网络抓包、CrossView、防火墙 | 采集与过滤仍保留原行数，工具带与现场结果分开 |
| HTTPS、NIDS、手动请求 | 补齐事件/级别/API下拉底色；代理操作、结果筛选和请求参数按任务分组 |
| WMI、ETW、进程跟踪 | 保留折叠和持续事件语义，调整参数、筛选、事件内容的层次 |
| 文件、IRP | 双面板导航与筛选下拉完整底面，保留路径和双表可见空间；IRP参数分组统一 |
| 注册表、优化项 | 路径、命令、搜索区明确，选择控件与输入恢复中性实底 |
| 窗口、GUI句柄、句柄、启动、服务 | 工具带和状态区层次统一，查询下拉与主表表头去除旧透明/强色覆盖 |
| 权限、账户、令牌、访问检查 | 参数输入对齐，同组紧凑，不同账号操作之间留白，选择控件底面完整 |
| 驱动 | 列表刷新、证据、查询和日志工具使用可见中性按钮底面，装载参数控件统一 |
| 内核 | SSDT、回调、CID、IPC、对象、派遣、IOCTL等普通表头改为中性底、正文色及单底分隔；不改变数据行颜色 |
| 硬件、电源、HWID | 控制区和参数分组收口，标题降低视觉重量，利用率自绘与浮窗保持原结构 |
| HVM | 生命周期与配置分区的区内、区间距统一，保留原操作流程 |
| 杂项 | BCD、磁盘、时间、位置、绘制、应用控制和剪贴板主页面按实际表单和事件区整理 |
| 扫描、转储 | 目标/符号来源形成紧凑工具带，扫描和解析作为主动作，编辑参数保留独立边界 |
| 欢迎 | 系统信息与项目社区分区，语言入口降低视觉重量，性能卡及动态字段保留 |
| 插件宿主 | 普通Tab独立拥有状态样式，移除旧强高亮覆盖；透明背景告警保留语义色并随主题更新 |

## 实现边界

`UI/PrimaryPageStyle` 提供页面显式调用的 Combo、Group、Toolbar、SectionTitle 样式。只替换自己拥有的样式片段，保留控件身份、业务信号、尺寸规则、原表格模型及数据语义色。主动作与辅助动作继续使用已有的 `FlatButtonTheme`。

本轮不执行生产 GUI、系统操作或驱动操作，也不追加对抗性审计。界面体验由用户运行编译产物验收。
