# 内存编辑器组件清单

2026-10-08：共享 `MemoryEditorWidget` 新增只读 **C 伪代码**页，HEX 和反汇编菜单可从选中地址发起真实 Ghidra 反编译；有语句地址的 C 行可定位回 HEX/反汇编。组件既有十六进制、反汇编、文本和对比页仍使用同一份字节缓存。后端配置、RAW/完整 PE 输入、资源限额及许可证边界见 [反编译后端](反编译后端.md)。

杂项中的扫描器新增文件区段总览横条和共享字节分析页：颜色区分文件头、代码、数据、资源及尾部附加数据；点击横条、区段下拉框、结构表或入口点均定位捕获快照。文件偏移、RVA、VA 按唯一且具有真实文件内容的 PE 区段映射换算，虚拟零填充、重叠歧义和溢出明确拒绝。扫描器保留稳定文件字节快照，组件每次仅加载最多 256 KiB，跨窗口浏览由宿主提供后续捕获字节。此入口没有文件内容写回动作。

核查日期：2026-10-02；文件共享查看页更新：2026-10-08。范围为仓库自有源码中的实际字节内存查看、暂存编辑及相关入口；第三方代码、磁盘扇区、文件字节、网络载荷和文本证据报告另列。主程序以 `Ksword5.1/Ksword5.1/UI/MemoryEditorWidget` 为共享展示与暂存组件，底层读写策略仍由各入口负责。

共享编辑器只显示一层十六进制/反汇编/文本/对比/C 伪代码页签，嵌入的 Hex 控件隐藏重复 HEX/ASCII 页签，保留表格 ASCII 列。反汇编指令和操作数列支持单击行内输入完整指令；Enter 暂存、Esc 取消，不弹窗。新指令只能覆盖原单条完整指令，缩短时以 NOP 填充；扩展覆盖范围或多行汇编需右键选择汇编编辑。提交前重新校验快照代次、架构和原字节，真实写回仍由页面的应用动作完成。

汇编表达式允许运算符周围的空白，拒绝把数字、寄存器或标签内部的空白静默拼接。核心回归为 `tools/memory_assembly_tests.cpp`；真实 Qt 行内编辑回归通过 `tools/Invoke-MemoryEditorUiTests.ps1` 复用已成功构建的 Release 对象，仅处理测试快照，不进行进程或驱动内存写入。

## 独立客户端的范围限制

`KswordARKLight/Features/Memory/DriverMemoryView.cpp` 仍使用原生 Win32 `EDIT` 控件，支持可编辑 Hex、Hex+ASCII、文本采样、历史快照、预览/应用差异与二进制导出。这是独立轻量客户端，不能直接挂载 Qt 的 MemoryEditorWidget；本轮主程序迁移没有为其新增汇编编辑。该实现不是 FLTK。

`KswordCLI` 的内存读写与 Hex 输出，以及 `CheatEnginePlugin` 的 memoryView SDK 类型，属于命令行和外部宿主协议；没有可替换的主程序 Qt 字节控件。

因此，本清单表示主程序交互式内存字节入口已统一；独立 Win32 客户端与上述文本/非内存字节工具继续保留各自实现，不声称全仓没有旧 Hex 组件。
