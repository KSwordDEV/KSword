# 内存与字节视图组件清单

2026-10-08：主程序统一使用 `UI/MemoryWorkbench/` 下的正式组件。旧 `HexEditorWidget` 门面、
`MemoryEditorWidget` 及其独立 C 页/分页比较实现已经删除，内存工作台不再保留旧查看器、
断点书签页、驱动读写页或回退路由。目标生命周期、共享后端、扫描证据、真实写入确认和回读保持独立。

## 统一组件

| 组件 | 职责 |
| --- | --- |
| `MemoryWorkbenchView` | 实时目标工作台：会话、地址、读池、缓存、立即/暂存写入、地址簿与 int3 补丁。 |
| `SnapshotWorkbenchWidget` | 捕获证据宿主：仅编辑已提供的字节与历史，宿主负责实际读取和写回。 |
| `HexView` / `HexCanvas` | 原生十六进制画布、选择、查找、跳转、解释器和导出；没有旧门面。 |
| `WorkbenchDisasmView` | 同一字节源的解码、定位、行内汇编与预览。 |
| `WorkbenchTextView` | 同一字节源的编码文本与显式结构视图，选择和编辑始终按源字节定位。 |
| `WorkbenchCompareView` | 同一虚拟比较模型，显示待写入和两次读取差异；静态宿主不再维护另一张分页表。 |
| `WorkbenchPseudocodeView` | 所有宿主共用的 C 伪代码、插件安装、取消及 HEX/反汇编定位。 |
| `AssemblyPreviewDialog` | 共用完整指令边界、NOP 补齐和预览外壳；宿主保留覆盖限额及提交方式。 |

实时工作台和快照宿主都提供十六进制、反汇编、文本、对比、C 伪代码五个子页。
反编译消费同一字节提供者：逐块复制并严格验证有效掩码，加载中等待宿主，未读/不可读拒绝。
身份、代次、输入字节或架构变化会使旧结果失效；C 页不会自行读取或写入目标内存。
RAW 与完整 PE 输入及资源上限见 [反编译后端](反编译后端.md)，运行环境通过
[上游分发协议](插件上游分发协议.md)从官方固定 Release 安装。

## 生产宿主

| 入口 | 组件与边界 |
| --- | --- |
| 内存工作台、内存调试、内嵌进程详情 | `MemoryWorkbenchView`，R3/R0/HVM/DDMA 权限和确认由正式目标与写入控制器管理。 |
| DDMA、HVM/R-1、影子页、Hook 补丁、内核反汇编证据 | `SnapshotWorkbenchWidget`；用户只修改缓存，实际应用、原字节核对、回读仍由各宿主负责。 |
| 文件查看 | `SnapshotWorkbenchWidget`，只读、按捕获文件窗口显示，偏移恒为64位；失败清空旧证据。 |
| Scanner 文件分析 | 同一快照工作台，节、文件偏移与 PE VA 单义映射；尾部、虚拟零填充、重叠和溢出拒绝解释为映像地址。 |
| Dump 内存块与转储页 | 同一只读快照工作台，保留捕获范围/身份；非VA辅助字节保留自己的文件偏移文本语义。 |
| 网络包/HTTPS载荷、注册表原始值、磁盘扇区 | 原生 `HexView`，复用同一画布；每种宿主的读写和验证协议保持不变。 |

快照不会因刷新或切换源而继承其它目标的待提交修改。对比只接受同一来源、范围和坐标域的
前次读取；关闭颜色高亮也不会隐藏实际差异。文件偏移不受所选 x86/x64 指令位数截断，
范围与末端地址加法必须可表示。

快照比较覆盖整份请求范围，以 64 KiB 分块扫描、按需呈现变化行，不再把 2 MiB 快照截成
前 1 MiB。单次比较上限 64 MiB；超限明确拒绝，不可读/加载中范围明确标记比较未完成。
换源或清空会立即失效比较索引，包括隐藏页和正在打开的定位菜单。

## 原生属性与原始正文

属性、审计、二级详情采用采集器直接生成的 `FieldDocument`，由
`StructuredFieldView` 呈现。`DetailLayoutHost` 在原生结构模型之间同步行内、嵌入和
浮窗，不经完整文本中转。复制和文本导出按需从模型生成，完整字段与所有 Tab 保留。

- `CodeEditorWidget::setRawText`：真实文件、协议、代码、正文和编辑输入。
- `appendRawText` / `replaceRawText`：流式日志，保留容量和阅读位置。
- 工作台字节文本：默认原始；完整有效 JSON/XML 可显式选结构。
- `TypedSyntaxDocument`：严格 JSON/XML 投影，保留数字词法；拒绝重复键、DTD/实体和超预算内容。
- 原生字段：工具栏、键盘和菜单共用模型复制，折叠/筛选不减少复制全部与导出内容。
- 字体、语言和主题可热更新；外部字段名和原始值不翻译，正文不改原文/撤销/选区。

旧报告解析、字段树包装以及生成报告文本的兼容入口已退役。

## 验证入口

- `tools/Invoke-KSwordBuildCheck.ps1`：标准 HostX64 Release/x64 主程序编译。
- `tools/Invoke-MemoryEditorUiTests.ps1`：链接实际生产对象，验证快照、文件映射、编辑/撤销/回读边界及共用 C 页契约。
- `tools/Invoke-UnifiedTextViewsTests.ps1`：实际 Qt 的原生字段/原文、严格 JSON/XML 预算、字节窗口有效性、行内/浮窗一致性。
- `tools/memwb_ui/build-memwb-ui-tests.cmd` 与 `wpJ6`：正式画布、比较和工作台装配。
- `tools/Invoke-DiskCaptureTransactionTests.ps1`：冻结来源、原字节冲突及实际回读的内存磁盘夹具。
- `tools/captured_disk_client_mock_tests.py` 与 `tools/captured_disk_kernel_mock_tests.py`：捕获 V2、同对象访问、异常完成量与请求写透的生产函数夹具。
- `tools/Invoke-RegistryMutationTests.ps1` 与 `tools/registry_review_regressions.py`：实际注册表事务/访问层和内存替换回归。

准确的事务与归档接口见 [共享呈现与捕获事务](共享呈现与捕获事务.md)。

这些隔离测试不等同于真实进程/驱动写入或正式 GUI 现场验收。独立 `KswordARKLight` 的原生
Win32查看器、CLI及第三方外部宿主不属于 Qt 主程序组件退役范围。
