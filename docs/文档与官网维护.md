# 文档与官网维护

文档入口为 [文档中心](README.md)，官网源码独立维护在 [Felix3322/KSwordWebsite](https://github.com/Felix3322/KSwordWebsite)。最近同步核对日期：2026-10-05。

## 来源与更新范围

| 内容 | 权威来源 | 同步位置 |
| --- | --- | --- |
| 主 Dock、辅助页与路由 | `MainWindow.cpp`、各 Dock 的页面构造代码 | 两份 README、使用指南、官网模块目录 |
| CLI 命令、别名和参数 | `KswordCLI.cpp` 的 help 元数据与实际 parser | 内置 help、`CLI使用文档.md`、官网 CLI 入口 |
| 协议与能力 | `shared/driver/`、`ioctl_registry.c`、`ArkDriverClient/` | 技术文档、相关专题与官网能力描述 |
| Windows 支持与报告 | Launcher 代码、源清单和实际发布 profile | 使用指南、构建与发布、官网兼容性说明 |
| 实验结果 | 有身份、环境、日期和运行态状态的原始证据 | 相关专题；产品介绍仅引用其覆盖范围 |

新增或改变功能时，先核对代码中实际入口与拒绝路径，再更新中文/英文介绍、所属技术章节和官网对应模块。不要把实现、离线测试、编译和实机验证写成同一状态。历史实验日志保留原样；过时的路线图在入口处标明历史性质并链接当前状态。

## 官网内容

官网是无框架的静态网站，可发布内容位于官网仓库的 `ksword-website/`。目录及页眉约定见该目录的 `README.md`：

| 位置 | 内容与维护要求 |
| --- | --- |
| `index.html`、`en/index.html`、`script.js` | 中英文首页、功能与截图；同步 HTML 与脚本双语文案，避免运行时覆盖回旧内容。 |
| `changelog.html`、`en/changelog.html` | 已发布与预发行版本历史；只记录对应发行身份。 |
| `development.html`、`en/development.html` | main 分支开发快照，包含尚未发行的源码变化。 |
| `hvm-topology.html`、`en/hvm-topology.html` | HVM 拓扑交互说明；同步当前机制与实验边界。 |
| `docs/`、`en/docs/` | 官网自有的开始使用、许可证、鸣谢与联系方式页面。 |
| `learn/index.html`、`learn/learn.js`、`learn/learn.css` | 文档中心外壳、目录清单、Markdown 读取与路由、样式。主仓库文档来自 `KSwordDEV/KSword@main`，增加专题时更新这里的目录与链接。 |
| `styles.css`、`script.js`、`en/script.js` | 共享基础样式、截图/按钮控制与实时 patch 数据读取。 |

所有页面保持中英语言路由和主导航一致，当前页通过 `aria-current="page"` 标注。主 Dock、辅助面板、设置与独立工具应分别描述；链接必须对应真实页面。详细技术内容链接或读取主仓库文档，避免再维护一套无来源的技术手册。

已有图片只有在文件真实存在时才作为截图展示。新的模块可用能力说明代替图片；截图拍摄计划与真实运行截图不能混淆。更新日志记录文档/官网同步内容，不伪称已经发行某个二进制版本。

## 验证与发布

1. 检查 Markdown 本地链接和新增索引目标，确认未把临时路径或个人机器目录写进指南。
2. 静态核对 CLI 文档与 help/parser，检查协议版本、能力门和兼容性文案。
3. 从官网仓库根目录运行 `node tools/check-site.mjs --source-root <KSword-checkout>`，验证 `ksword-website/` 的本地链接、锚点、页面资源与主仓库文档目标。
4. 用 `python tools/preview-site.py --source-root <KSword-checkout>` 预览本次 Markdown；检查首页、操作指南、文档中心、开发快照、更新日志、七步拓扑、中英路由、筛选、窄屏和页内导航。
5. 在官网独立仓库保存可审查的 diff。文档中心新增的主仓库路径先合入 main，再按既有部署方式发布官网。源码已更新、已提交、已上线是不同状态，分别报告。

更新主程序可见文本时仍须同步两份语言包并执行仓库 i18n 审计；单纯修改 Markdown 和官网网页不改变主程序词条。
