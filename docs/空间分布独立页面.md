# 空间分布独立页面

## 导航与布局

| 导航入口 | 类型 | 共享入口与责任 |
| --- | --- | --- |
| 文件 → 快速文件搜索 | 参数执行 + 文件结果列表 | `ParameterWorkspace`、`StyleWorkspaceContentFrame`、共享工具带、`ResultTableHost` Compact；MFT/USN 只负责搜索 |
| 文件 → 空间分布 | 目录范围选择 + 参数执行 + 目录清单 + 面积图 | `DirectoryScopePicker` 与 `ParameterWorkspace::setParameterViewport`；范围树独立滚动、占据可用高度，开始/停止固定；目录树使用 `TablePresentation` None，扩展名使用 `ResultTableHost` Compact，图复用 `NtfsSpaceMapWidget`/`MetricAreaRenderer` |
| 文件 → 文件管理 | 文件浏览、导航、操作 | 保留已有面包屑、地址栏和文件视图；手动解析只能显示单目录时禁用树形选项，并解释需要 Windows API 模式 |
| 杂项 → 扫描器 | 单文件分析 + 专业编辑 | 保留文件类型过滤的原生选择器和现有共享工具带、结果容器、编辑器；选择仅设置目标，扫描按钮/Enter 执行，结果来源单独注明 |

普通遍历为默认方式，初始范围为空。左侧直接显示可展开的磁盘/目录树，选择磁盘本身可扫描整个卷，选择子目录只扫描相应范围；选择或切换方式不会启动扫描。目录浏览仅按用户展开读取目录，空间统计仍需显式点击开始。选中路径显示为摘要而非主要输入方式。

范围树是只读、单选、单列目录模型；不套搜索结果的复制、导出或快照操作。它直接使用自身滚动，避免固定小树再嵌套外层表单滚动。扫描方式和计量口径均用可直接选择的分段控件；说明保留在相应提示中。结果树支持鼠标与键盘选择，面积图进入目录、上一级、取消和失败回退同步当前结果树身份。

页面参照 `MiscDock/SystemTime/SystemTimePage.cpp`、`MiscDock/VirtualLocation/VirtualLocationPage.cpp` 和原 MFT 空间结果实现。使用标准控件主题、参数分区、统一工具带；页根 6px 留白只由共享内容框负责，不嵌套新的结果 Tab 或外框。路径和动态状态使用纯文本。

## 相关控件用途审查

- 文件管理：保留文件/目录混合浏览及已有面包屑，不改为仅目录选择器。手动原始文件系统/R0 数据模型是单目录列表，禁用不具备真实层级的树形选项；不使用普通文件系统模型冒充该来源。
- 快速搜索：MFT 索引源是整个本地 NTFS 卷，保留卷选择框；关键词是搜索条件，继续使用搜索输入。
- 误删恢复：来源应选卷，已删除的目录不能依靠当前文件夹树找到；导出目标使用原生目录选择器并保留显式恢复动作。
- 二进制扫描器：目标是单个 PE/ELF/Mach-O/镜像文件，保留带类型过滤的文件选择器；修正选文件即扫描的隐含动作，并标出当前结果实际来源，避免新目标与旧结果混淆。
- 共享组件只承担其职责：参数工作区管理分栏/固定动作，树负责层级与浏览，结果宿主管理可复制/导出的结果。`setParameterViewport` 为明确选择的页面提供自带滚动的正文入口，其他页面继续使用原表单滚动逻辑。

本次审查范围是上述相关入口和组件，不代表全仓库所有页面已完成用途或视觉验收。

## 数据与生命周期

- 普通方式支持当前账户能够访问的文件系统，不依赖原始 NTFS 卷句柄。只查询默认数据流的逻辑/分配大小；跳过重解析点和脱机召回项，按卷/文件身份对硬链接去重。
- 扫描保持祖先目录元数据句柄，防止遍历中的中间目录被替换成联接点。祖先句柄只在其后代处理期间保留；未计量文件、跳过目录和链接显示覆盖提示。
- MFT 方式需要本地 NTFS 和相应权限，读取所在卷索引后裁剪所选子树。硬链接即使规范名称在范围外，范围内另一个名称仍可计量一次。目录链接保留本体，不把其目标后代算入所选范围。
- 扫描、目录聚合和扩展名汇总均在后台。停止/失败保留上次结果；改变参数时旧结果明确标注来源。取消延期提交不会替换旧快照。
- 目录、文件类型和面积图引用同一快照；上一级不越过扫描根。目录与计量方式的取消回退同时恢复已显示身份及口径。文件定位继续使用原 FileDock 异步导航。
- 面积是已计量文件大小，不等于卷全部已用空间。备用流、目录索引等元数据及空闲空间不在该面积内。
