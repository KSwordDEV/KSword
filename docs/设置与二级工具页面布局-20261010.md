# 设置与二级工具页面布局

## 设计目标

参考用户提供的设置页，保持有用信息密度，减少重复边界、杂乱对齐和过强装饰。布局与 Tab 数量服从实际任务：需要同时填写或比较的参数与结果放在同一视野，独立配置保留分类导航。属性、详细信息、只读证据报告不接入本轮配置窗口外观。

## 设置

- 顶部文字 Tab 与细选中线固定；每个页面内部滚动；应用、取消固定在底部。
- 外观左侧放主题、背景和透明效果，右侧放待应用预览、交互、通知及权限显示。窄窗口按内容顺序纵排。
- 主题模式使用有文字的三段选项；主题色和背景色直接显示色块及 HEX。预览保留未应用状态，应用才保存。
- 长解释放在对应控件提示中，直接操作和重启生效的说明保留可见。标签齐列、同组控件等高。
- 语言、启动、功能、在线扫描继续沿用原分类，移除重复卡片边界，整理表单与操作行。

## 按用途整理的二级窗口

| 范围 | 取舍 |
| --- | --- |
| 进程列表设置、列选择、扫描设置 | 配置按采样、显示等用途分区，标签与控件同行；即时设置仍即时生效 |
| 防火墙规则 | 规则身份与网络范围同屏双栏，避免编辑时来回翻页 |
| 路由编辑、下载确认、监控目标、手动地址 | 紧凑表单与固定操作区，不给小表单强加 Tab |
| 句柄规则编辑、规则管理 | 字段对齐；列表管理动作靠近列表，关闭区独立 |
| 插件管理 | 保留原分类 Tab，采用文字导航；协议确认保留原接受与取消语义 |
| 新建桌面 | 基础、安全设置与访问掩码、参数摘要自适应并列；主体滚动、操作固定 |
| 注册表值、离线 Hive、导入预览 | 保留编辑器与原 Tab；保存、另存工作副本和关闭归入明确操作区 |
| AppLocker、WDAC、Defender、ASR、剪贴板规则 | 按实际字段关系整理表单；代码编辑保持主要空间 |
| 文件解锁、列管理 | 保留目标列表与业务动作，统一内容和操作边界 |
| IRP 派遣、DriverObject 镜像、UEFI、内核字节编辑 | 编辑字段与原证据同屏，保留原事务、确认和回读逻辑 |
| 汇编编辑 | 代码与机器码预览同时可见，通过分隔条调整空间 |
| 字符串写入、指针链书签 | 内容、编码或名称与目标对齐；原校验与状态反馈保留 |
| HVM 执行域、CR、MSR、分离视图、内存操作 | 参数与结果同屏，固定动作和状态区；规则清单不重复提供快照栏 |
| HVM 进程处置、内存监视、Hook 向导 | 保留原分类与五步校验流程，仅整理表单、访问位和导航操作区 |

## 共享实现边界

`UI/SecondaryPageLayout` 由具体窗口明确调用，不扫描所有弹窗，也不修改全局属性详情样式。配色来自主题角色并随主题刷新；局部输入、分区、Tab 和底栏各自拥有样式。双栏只在宽度跨断点时调整位置，不重建业务控件。

本轮不启动生产 GUI，不执行操作窗口中的系统或驱动动作。界面体验由用户运行新版程序验收。
