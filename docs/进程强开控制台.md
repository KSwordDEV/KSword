# 进程列表强开控制台

入口：**进程 → 进程列表 → 进程右键 → 强开控制台**，位于 DLL/Shellcode 注入入口下方。
沿用列表多选及应用聚合行的目标展开语义；每个目标独立执行并通过现有日志、通知反馈。
未取得真实创建时间或仅内核可见的目标禁用此动作，并提供原因提示。

## 执行范围

将 WindowsMarker 的 `StartConsole` 流程迁移到 `shared/usermode/ProcessConsole.*`：

1. 在具有执行权限的同一个进程句柄上验证 PID、创建时间及存活状态。
2. 在目标上下文查询 `GetConsoleWindow`，没有窗口句柄时执行 `AllocConsole`。
3. 打开 `CONIN$` / `CONOUT$`，设置 Win32 标准输入、输出、错误句柄及 UTF-8 代码页。
4. 目标已加载 UCRT 时，通过该运行库的 `__acrt_iob_func` 获取目标 `FILE*`，执行
   `freopen_s` 及输出/错误无缓冲设置。
5. 目标已加载 MSVC14 STL 时，执行 `sync_with_stdio(true)`，清除 `cout/clog/cerr`
   及三个宽字符对应流的错误状态。通过目标的虚基表读取 `basic_ios` 地址，不猜对象大小。

这条路径不携带、落地或加载自定义 DLL，也不调用本机 `AttachConsole`。调用地址由目标
模块解析，主程序内置两种架构的短调用例程；x86 的 stdcall/cdecl/thiscall 与 x64 的
寄存器参数、shadow space 和栈对齐分别处理。代码页先 RW 写入再改 RX，参数页保持 RW。

运行库边界与原功能一致：不能通用恢复静态/私有 CRT 或不同语言的输出机制，不能恢复过去
已丢失的输出。未检测到对应共享运行库时，仍可完成 Win32 层，并在结果明细说明该层未处理。
目标现有共享运行库的某一步执行失败时返回失败，明细保留已完成层和失败阶段。
已有控制台时不额外显示窗口，也不创建第二个控制台，不新增命令解释器或驱动回退。

## 资源与异步

UI 冻结菜单打开时的目标快照并复用 `dispatchProcessActionTargetsInParallel`；单目标也异步
执行，后端不依赖 Qt。正常线程完成后释放调用代码/参数页；单次远程调用最多等待五秒，
整体远程步骤共用十秒截止时间。等待超时不终止目标线程，不释放其仍可能使用的内存，
结果报告未完成及远程页保留至目标退出；不会在超时后继续复用调用包。

## UI 接入核对

| 入口与类型 | 共享入口与检查 |
| --- | --- |
| 进程列表右键；主列表上的进程动作 | 复用原 `TablePresentation`、Full 表格操作、`buildThreadContextMenuStyle` 与主题图标 |
| 请求及结果 | 捕获真实 PID+创建时间；复用原异步动作、逐目标日志和结果反馈，不增加参数页或弹窗 |
| 同类实现参照 | 进程挂起/恢复菜单；FileDock 文件表格右键及主题样式 |

没有新增或重排页面、Tab、表格列组、详情数据源、复制/导出或专业控件结构。新增动作保留文字、
终端图标及双语悬停释义；菜单沿用明确的背景、文字、选择和禁用态样式。

## 验证

`tools/process_console/Build-ConsoleFixture.ps1 -Architecture x64` 与 `-Architecture x86`
以 HostX64 MSVC `/W4 /WX` 构建动态/静态运行库夹具及真实生产后端。
从 x64 宿主分别操作两种位数的两种夹具，检查错误创建身份不会产生控制台，正确身份首次
和重复执行均成功，最后目标正常退出。

动态运行库夹具预置六路 C++ 流为错误态，然后在目标业务线程实际输出并读取控制台缓冲区：
Win32 一路、C 两路、C++ 窄/宽共六路，全部九路匹配（位图 `0x1ff`）。同时验证 C 标准输入、
Win32 句柄及 UTF-8。静态夹具只验证 Win32 输出和结果中的运行库边界说明。

另以真实远程 `Sleep` 超过五秒等待，验证后端报告未完成、会话析构后参数页仍为已提交，
迟到线程返回后目标业务线程仍能正常响应。该路径未强制结束线程或提前释放远程页。

`verify_live_console.py --pid GUI_PID --fixture TARGET_EXE` 通过主程序现有 MCP 本地桥选中
自有夹具，打开真实右键菜单并点击动作，再以目标输出回读确认后端完成。已在真实 Release
主程序完成 x64、x86 动态夹具两条路径；当前浅色菜单、图标和释义已核对。不是只触发 QAction
回调或只检查远程线程退出码。

尚未完成：深色主题、窄窗口、不同 DPI/字体缩放和背景模式下的菜单视觉验证；任意第三方
进程/系统版本组合的兼容性不由上述受控夹具证明。
