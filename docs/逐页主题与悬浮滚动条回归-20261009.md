对抗性审查固定基线：`0d4d839043eedb254701cc53ab6c5fc8009b3948`。
`2c796a6d` 不作为干净基线。此次检查包括基线以后已提交的进程 GPU 实验、表格染色/平滑滚动修复，以及本轮逐页适配。

## 实现边界

- 滚动条为内容边缘的悬浮细线，透明轨道，常态 3px，悬停/拖动 5px；命中带 10px，随浮窗倍率缩放。原生条布局厚度为零，不占内容宽度。
- 原生 `QScrollBar` 对象、策略、量程、步长、业务信号及平滑滚动入口保留。没有添加第二套滚轮算法，没有改文字编辑器视觉行或大地址画布的滚动单位。
- 按钮只共享不透明填充和状态色；普通、强调、危险、成功色调由页面明确选择，原尺寸、文字/图标、tooltip、信号连接、checked/enabled 语义保留。
- 未标记的本地或祖先 QSS 保留页面所有权。全局规则不猜测按钮文本、不跨越未知样式覆盖数据色、不改表格 item 绘制。
- 数字控件分别绑定外层及 `qt_spinbox_lineedit` 的文字/表面色；历史值 50、后缀、验证器、步进和布局不变。
- GPU 进程列表仍是显式实验开关 `KSWORD_PROCESS_LIST_GPU=1`，默认光栅。GPU 失败后保留模型、选区、冻结区和滚动位置并回退。

## 独立对抗性审查

两名独立审查者分别检查 Standards 与 Spec/行为，固定使用上述用户基线，读取 staged 与后续修复。报告不以旧构建产物或组件通过替代生产 GUI 验收。

### Standards 原始发现与处理

P2：硬件利用率浮窗 200% 缩放后归还，控制器仍保留 2.0，导致主窗口滚动条厚度与鼠标命中带残留。归还循环现对所有捕获且存活的 `QAbstractScrollArea` 恢复 1.0；审查者读回确认该项静态消除。

### Spec/行为原始发现与处理

1. P2：按钮先用共享样式再改数据色，旧绑定在主题刷新时重新追加规则。现刷新先核验实际标记所有权；首次许可使用共享状态，兼容 ThemeBinding 复制回调后的寿命。
2. P2：先 Neutral 再显式 Danger，首次 Show/Polish 会读取旧 marker 降回 Neutral。现待应用的显式 tone 优先，真正重写本地 QSS 时仍允许 A/B 状态更新。
3. P2：普通按钮 hover 改为中性实底，旧 SVG Active 仍按强调底求色。现仅单色主题候选的共享按钮建立独立弱上下文引擎，按实际状态底色校准 3:1。默认主题也覆盖共享强调按钮；菜单、模型、Tab、多色图标维持各自语义。

修复复核还发现未知祖先 QSS 被全局 marker 误认的问题，现自动绑定和图标查询遇到未知祖先覆盖都停止推断，并用真实控件帧验证数据底色。另补上主窗口三个菜单按钮及标题栏六个功能控件的逐项适配。

审查者读回未确认上述路径仍有残留、上下文缓存串色、刷新循环或恢复默认时源图误捕获。测试前置声明问题已经修正。最终构建及回归结果见下一节。
