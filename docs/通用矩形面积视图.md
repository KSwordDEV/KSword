# 通用矩形面积视图

面积用于比较同一种可量化指标。进程网络支持“上行 / 下行 / 合计”，分别使用发送、接收及两者之和；切换模式只重新投影当前快照，不重新采样。标题、数值、百分比和复制单元格使用同一方向。

## 入口与指标

| 导航入口 | 指标与数据范围 | 共享布局 |
| --- | --- | --- |
| 进程 → 进程列表 → CPU、网络等度量列表头右键 → 矩形面积视图 | 已提交主列表的原始指标；网络三种方向，保留树、友好分组与历史快照 | `MetricAreaWindow`、`MetricAreaCanvas` |
| 进程详情 → 模块 → 矩形面积视图 | 当前筛选后已提交模块列表的虚拟映像大小；不等于驻留内存 | 同上 |
| 内存 → 系统内存审计 → 用户态驻留 → 矩形面积视图 | 私有驻留、驻留引用、共享引用和比例估计；引用不是唯一物理页 | 同上 |
| 内存 → 系统内存审计 → 内核进程快照 → 矩形面积视图 | 私有驻留、工作集、提交、配额、硬缺页和增量 | 同上 |
| 内存 → 系统内存审计 → Pool 标签 → 矩形面积视图 | 分页/非分页/合计字节、分配计数及增量；提交与驻留分开 | 同上 |
| 内存 → 系统内存审计 → Big Pool 分配 → 矩形面积视图 | 分配大小、大小变化绝对值，数值保留正负号 | 同上 |
| 内存 → 系统内存审计 → PFN 深度归因 → 矩形面积视图 | 默认已用页的进程归属层级；另有完整分类、页面状态、backing、活跃页及归属覆盖指标 | 同上 |
| 内存深度归因 → GPU 消费者 | 按实际数据范围分别比较进程/适配器的共享、专用等量化指标 | 同上 |
| 内存 → Hyper-V | 分区、进程、同单位宿主计数器及提供者行数；排除重复总计和冲突 VID | 同上 |
| 内存 → 池分配分析 | 当前筛选及分组的字节、次数和增量；与原历史快照同步 | 同上 |
| 硬件 → 硬盘监控 → 卷队列 → 矩形面积视图 | 已提交卷样本的读取、写入、合计速率；等待基线或采集失败为不可用 | 同上 |

内存页面的共同工具栏根据当前结果页打开对应图表。打开图表不会启动深度扫描、PFN 查询、进程模块枚举或磁盘采样。没有已提交数据时，入口禁用并说明依赖；扫描失败保留旧图时仍显示旧快照身份与失败状态。

PFN 默认图按已确认 PID＋创建时间组织进程，下面是互不重复的私有归属证据和页面状态；系统、共享及未解析的已用页独立分组。可用、坏页、读取失败与未扫描不参与默认进程面积，但保留计量并可切换到完整台账视图。索引型 backing/状态叶键绑定扫描 epoch，新扫描重排不会把旧缩放位置误用到另一对象。纯地址、对象身份、解释与日志页保留原详情，不把 ID 当作资源面积。

## 组件约定

- `MetricAreaNode` 提供稳定 `key`、名称、通用 `identity`、原始面积 `weight`、格式化数值、提示和可选父项。地址、PID、状态值不作为面积。父分组不另造重复叶格；进程父项自身资源与子树资源分开计入。
- `MetricAreaWindow::setSubject` 声明对象名称、标识列和操作说明；`setModes` 提供指标目录。选项能完整显示时使用共享分段栏，窄窗或长目录使用完整文本下拉框。程序更新不触发业务回调，用户选择只触发一次。
- `itemActivated`、`itemContextRequested` 由宿主按稳定键处理。宿主保留采样时的业务身份和代次，不能用当前排序位置重新解释旧图。进程菜单继续校验 PID 与创建时间。
- 零值和不可用项不伪造最小面积；底部以轻量模型完整列出，操作条为 None。矩形支持放大、返回、悬停和稳定键恢复；无效权重不参与面积，几何归一化防止大数求和溢出。
- 不从本地化显示字符串反推数值。模块使用原始大小角色；内存使用不可变投影的数值角色；PFN 使用核对过的物理页台账；卷速率使用原有采样差分。
- 组件不拥有业务采样器或定时器。内存大表的节点格式化在后台完成，提交时核对原投影和模式；隐藏图表不停止原页面承担的业务采样。

共享窗口归类为二级图表工具窗：使用 `SecondaryPageLayout`、共享工具行和内容面，页根留白单层负责。画布保留专业内部结构；不接入属性详情卡片重排。模块与内存的新增工具入口使用共享换行布局适配窄窗。
